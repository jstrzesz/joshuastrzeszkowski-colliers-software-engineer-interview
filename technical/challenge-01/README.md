# Technical challenge 01: Joke Page

> **All submissions should include a clear statement of whether or not AI tools were used and, if so, how they were used. Submissions without this statement will not be considered.**

This challenge asks you to display a joke retrieved from an API on the page. You're provided with some boilerplate code to get you started. Here are the general steps you'll need to take to complete the problem.

(**Note**: For this part, you should not need to modify "package.json".)

1. Start the API by running `npm start` in the "api" folder.
2. Start the UI by running `npm start` in the "ui" folder. This should open your browser. You'll see a placeholder message there.
3. Modify the API to return a joke from [icanhazdadjoke.com](https://icanhazdadjoke.com/) from the `/jokes` endpoint.
4. Modify the UI to call the API endpoint to retrieve a joke and display the returned joke on the page.

Include in your PR description any challenges you faced with implementing the solution.

If you are applying for a senior software engineer position, find **5 ways** to make this implementation more robust or 
interesting. Implement those ideas. Make one commit for each change so they can be clearly identified in the branch 
history. *Do not add any new packages.* Create your PR with all of those changes implemented.
