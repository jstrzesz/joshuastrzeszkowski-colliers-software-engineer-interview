# Colliers Technology & Innovation Software Engineer Interview Challenges

These challenges shouldn't take more than 30—60 minutes.

Follow the directions very carefully. If you have questions, contact Doug Mulley (doug.mulley@colliers.com) and Colin
Vinson (colin.vinson@colliers.com) (include both in the email).

> **All submissions should include a clear statement of whether or not AI tools were used and, if so, how they were used. Submissions without this statement will not be considered.** 

## Getting started

1. Add all of the files provided as your starting point into a new local git repository.
    1. Expand the zip file.
    2. Initialize the directory as a git repository (`git init`).
    3. Add all of the files (`git add --all ./`) to the new local instance of the repository.
    4. Commit with the message "Starting point" (`git commit -m "Starting point"`).
2. Create a _private_ GitHub repository in your personal GitHub account. Name the repository "<github-username>
   -colliers-software-engineer-interview". Replace "<github-username>" with your GitHub username. For example, Doug
   Mulley's GitHub username is "dougmulley". His repository on GitHub would be "
   dougmulley-colliers-software-engineer-interview". **Note**: Be sure to create an empty repository. Don't let GitHub
   prepopulate it with a README, `.gitignore`, or license.
3. Add the new GitHub repository as a remote to your local repository. The directions to do this should be on the GitHub
   page for your new, empty repository under the heading "…or push an existing repository from the command line". They
   should look like this:
    ```
    git remote add origin git@github.com:<github-username>/<github-username>-colliers-software-engineer-interview.git
    git branch -M main
    git push -u origin main
    ```
4. Back in GitHub, go to the Settings page for the repository. On the Collaborators tab, add Doug Mulley (dougmulley)
   and Colin Vinson (cvinson) as collaborators on the repository.

## Challenge 01: Joke Page

1. Create a branch from the HEAD of the "main" branch. Name the branch "challenge-01".
2. Navigate to [Challenge 01: Joke Page](technical/challenge-01/README.md).
3. Implement your solution for the challenge in the "challenge-01" branch. Create incremental commits, not one large commit at the
   end.
4. Push the solution branch to GitHub.
5. Create a GitHub pull request to merge the "challenge-01" branch into the "main" branch. Add Doug Mulley (dougmulley) and Colin
   Vinson (cvinson) as reviewers on the PR. In the PR description, please note the approximate total time that you spent
   creating the solution. (This will help us to gauge if we've made the problems too time consuming.)
